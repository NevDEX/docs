# NevDEX Contract Addresses

This document lists the NevDEX Vault and Exchange contract addresses for project configuration and contract integration.

## Contract Addresses

| Contract | Environment Variable | Address |
| --- | --- | --- |
| Vault | `VAULT_ADDRESS` | `0xcb302295C32a6630d099F86CD1d8284F804E0cFB` |
| Exchange | `EXCHANGE_ADDRESS` | `0x6392380dFb48DD683f1FFACe76deA039692EE525` |

## Environment Configuration

Add the following addresses to your project's `.env` file:

```dotenv
VAULT_ADDRESS=0xcb302295C32a6630d099F86CD1d8284F804E0cFB
EXCHANGE_ADDRESS=0x6392380dFb48DD683f1FFACe76deA039692EE525
```
